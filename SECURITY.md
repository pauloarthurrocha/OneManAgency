# Security Policy

## Supported Versions

Currently, only the `main` branch and the latest released version are receiving security updates.

| Version | Supported          |
| ------- | ------------------ |
| 4.x.x   | :white_check_mark: |
| < 4.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in OneManAgency, please do not open a public issue.

Instead, send an email to the repository owner directly, or use GitHub's private vulnerability reporting tool in the Security tab of this repository.

We take security seriously, especially considering this framework orchestrates code generation on local machines. We will endeavor to respond and patch any exploits (e.g., prompt injections that could lead to unauthorized local execution) as quickly as possible.
